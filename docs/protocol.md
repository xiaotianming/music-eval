# 评估协议 v1.0

## 输入与分组

每条样本关联原音频 SHA-256、prompt_id、提示词原文及可选英文评分文本、model_id、model_version、audio_type、seed、标签及用途。上传清单不读取任意本机路径；音频必须同时上传。参考集与生成集严格区分。

模型组 = `(model_id, model_version, audio_type)`。提示词是比较的统计单位：同组内先对同提示词的多个样本平均，再对有效提示词等权平均。不对缺失/失败/不适用结果补零。用户需保证同 prompt_id 表示同一提示词及测试条件；本系统不推断 seed 在不同生成器中的等价性。

## CLAP 与长文本

固定 `laion/larger_clap_music` 修订，CPU float32，无梯度，batch size 1。原音频转单声道后用 `scipy.signal.resample_poly` 重采样至 48kHz，不做响度归一化。使用连续 10 秒窗，尾段零填充。对每个音频嵌入和文本嵌入做 L2 归一化；单窗分数为余弦相似度，全曲按原始有效时长加权。

中文在本地通过固定 OPUS-MT 中文到英文模型翻译，240 token 分段、4 beam；英文原文直接使用。译文可独立查看和修订。CLAP 长文本以最多 75 个内容 token 分段，各段嵌入按 token 数加权后再 L2 归一化；不静默截断。不把分数线性改写为百分比。

音频嵌入缓存键包括内容哈希、模型修订、采样率、窗口/步长/尾段策略、协议版本。文本结果另外包括原文、译文及翻译模型修订。修改译文不会重复提取音频嵌入。

## SongEval

校验固定 Git 修订、关键源文件无修改及权重 SHA-256。使用与官方一致的 `librosa.load(sr=24000)`、完整音频 MuQ 推理、hidden state 6、原 Generator。歌曲输出 Coherence、Musicality、Memorability、Clarity、Naturalness；纯音乐默认跳过，显式开启后仅报告前四项并标注探索性。不截短输入，不平均片段来替代全曲结构。

## FAD

固定 FADtk 修订、`clap-laion-music` 和原 LAION 音乐 checkpoint。以 48kHz 单声道、10 秒窗口、1 秒 hop、尾段零填充提取嵌入，保留上游 int16 量化及 float16 缓存行为；聚合时转 float64。音频重采样使用本系统固定的 scipy polyphase，因此跨论文比较必须确认预处理一致。

为避免上游在加载完整 CLAP 权重前下载未固定的 RoBERTa 权重，初始化阶段使用固定 RoBERTa 配置/分词器建立相同模型结构，再由上游 **strict=True 的完整权重加载** 覆盖全部参数。没有替换推理，也没有使用模拟评分。

使用 FADtk 均值/协方差估计。协方差常因小样本奇异，距离采用等价的对称 PSD 特征分解公式，避免上游对非对称协方差乘积求逆时数值不稳定。该实现标为 `symmetric-psd-eigh-v1`，分数为有限样本 FAD，不是 FAD∞。

FAD 始终附带参考音频哈希/类型/标签、样本量、时长、窗口数、模型与协议。只筛选相同音乐类型，风格与场景是否匹配由参考集标签和研究设计确定。缺少参考集显式跳过；同一音频哈希不可跨生成集与参考集。参考音频不随软件分发。

## 报告与解释

- 分项均值、中位数、P10/P90 均基于提示词内平均后的值。记录每项有效提示词数。
- 配对比较只使用同类音乐的共同有效提示词；差异定义为 A − B，固定随机种子 2026，2,000 次按提示词重采样，取 2.5% / 97.5% 分位数。少于两个共同提示词不计算区间；少于 20 个提示词提示探索性。
- 美学相关性是有效单曲分数的描述性 Pearson 相关，不视作维度独立性检验。
- 各指标的缺失/跳过/失败/过期结果分别计数，报告成功数相对于该模型组全部样本的比例。
- 盲听使用匿名随机 A/B、平局或跳过，投票后揭晓。人工胜率 = 胜 /（胜 + 负）；平局与跳过单列，与自动指标不混合。
- 不提供综合总分或通用合格线；不声称 CLAP 可验证歌词、精确结构或所有否定指令，也不声称基础 DSP 或 FAD 足以替代主观音质判断。
